# 知识图谱可视化 - 使用说明

## 📊 功能概览

知识图谱页面是费曼学习平台的核心可视化功能，通过力导向图算法将知识点之间的引用关系以星系般的视觉效果呈现，帮助用户宏观把握知识体系结构。

---

## 🎨 界面说明

### 1. 星空主题背景
- **多层星空动画**：模拟真实星空的深度感，包含两层星星漂移动画和星云脉动效果
- **渐变星云**：蓝色、紫色、绿色星云交织，营造宇宙氛围
- **玻璃态卡片**：半透明毛玻璃效果，与深色背景完美融合

### 2. 节点（知识点）视觉设计
每个节点代表一个知识点，采用**行星渐变**设计：
- **中心高亮**：白色核心，象征知识的光芒
- **状态颜色**：
  - 🔵 **蓝色**（`#3b82f6`）：学习中
  - 🟢 **绿色**（`#22c55e`）：已掌握
  - 🟠 **橙色**（`#f59e0b`）：需复习
  - ⚪ **灰蓝**（`#64748b`）：未开始
- **大小自适应**：节点大小根据知识点内容长度动态调整（16-60px）
- **光晕效果**：每个节点带有与状态颜色匹配的阴影光晕

### 3. 关系边（引用关系）
- **半透明连线**：灰色半透明线条，不干扰节点视觉
- **曲线美化**：12% 曲率，避免直线的生硬感
- **聚焦高亮**：鼠标悬停节点时，相邻关系边自动加粗高亮

## 🎮 交互操作指南

### 基础交互
| 操作 | 说明 |
|------|------|
| **鼠标滚轮** | 缩放画布（支持无限缩放） |
| **拖拽空白区域** | 平移整个图谱视图 |
| **拖拽节点** | 移动单个节点位置 |
| **单击节点** | 跳转到该知识点的编辑页面 |
| **双击节点** | 固定/解锁节点位置（固定后节点不受力导向算法影响） |
| **悬停节点** | 显示详细信息卡片（标题、状态、内容预览） |

### 高级功能

#### 🔍 搜索与过滤
- **标题搜索**：输入关键词实时过滤节点（不区分大小写）
- **状态筛选**：下拉菜单选择特定学习状态的知识点
  - 全部状态
  - 未开始
  - 学习中
  - 已掌握
  - 需复习

#### 🏷️ 标签显示控制
- **智能显示**：默认仅在缩放 ≥ 1.1 或节点较大时显示标签，避免拥挤
- **强制显示**：勾选"显示全部标签"复选框，始终显示所有节点名称

#### 🔄 布局控制
- **重新布局**：点击后轻微扰动力导向参数，触发图谱重新计算布局（适用于节点重叠或布局不理想时）
- **重置视图**：恢复初始缩放和位置，清除所有固定节点

#### 💾 导出功能
- **导出 PNG**：将当前图谱视图导出为高清图片（2倍像素密度，深色背景）
- **导出 JSON**：导出当前过滤后的节点和关系数据（可用于数据分析或备份）

## 🚀 性能优化特性

### 1. 渐进式渲染
- **动画阈值**：节点数 > 2500 时自动降低动画复杂度
- **渐进渲染**：大数据集分块渲染（每 2000 个节点一批）
- **悬停层阈值**：节点数 > 3000 时优化悬停检测

### 2. 智能更新策略
- **lazyUpdate**：延迟更新，减少不必要的重绘
- **notMerge: false**：增量更新配置，避免全量重绘
- **缩放节流**：缩放变化 < 0.02 时不触发状态更新

### 3. 布局算法优化
- **斥力系数**：320（可通过"重新布局"微调）
- **边长范围**：60-120px（自适应调整）
- **摩擦力**：0.2（快速收敛）
- **重力**：0.05（保持整体聚合）

## 📐 数据结构说明

### 后端 API 响应格式
```json
{
  "nodes": [
    {
      "id": "节点唯一ID（MongoDB _id）",
      "name": "知识点标题",
      "value": "内容预览（前100字符）",
      "status": "not_started | in_progress | mastered | review",
      "reviewList": true/false,
      "symbolSize": 20-36
    }
  ],
  "links": [
    {
      "source": "源节点ID",
      "target": "目标节点ID"
    }
  ]
}
```

### 关系发现规则
后端通过**内容匹配**自动发现关系：
- 遍历所有知识点 A
- 检查 A 的 `content` 是否包含其他知识点 B 的 `title`
- 若包含，则建立 A → B 的引用关系

**优化建议**：
- 标题长度 ≥ 2 字符（避免误报）
- 去除空格后匹配（提高准确率）

- 悬停查看引用关系
- 通过搜索定位特定主题

### 4. 可视化展示
- 导出高清图片用于学习报告
- 分享知识体系给他人

## 🐛 常见问题

### Q1: 节点重叠怎么办？
**A**: 点击"重新布局"按钮，系统会微调力导向参数重新计算。也可以手动拖拽节点到合适位置，双击固定。

### Q2: 标签太多看不清？
**A**: 取消勾选"显示全部标签"，系统会智能显示（仅在缩放或节点较大时显示）。

### Q3: 如何找到特定知识点？
**A**: 使用顶部搜索框输入关键词，图谱会自动过滤并只显示匹配的节点及其关系。

### Q4: 导出的图片太暗？
**A**: 导出的 PNG 使用深色背景（`#0b1220`）以匹配星空主题，可在图片编辑软件中调整亮度或背景。

### Q5: 为什么有些知识点没有连线？
**A**: 说明该知识点的内容中未提及其他知识点的标题，或其他知识点未引用它。可以在编辑时增加相关术语。

## 🔧 技术栈

- **图表库**：ECharts 6.0 + echarts-for-react 3.0
- **布局算法**：力导向图（Force-directed Graph）
- **渲染引擎**：Canvas（高性能）
- **状态管理**：React Hooks（useState, useMemo, useCallback）
- **样式方案**：CSS 渐变 + 毛玻璃效果 + 关键帧动画

## 📈 性能指标

| 节点数量 | 渲染时间 | 交互流畅度 | 建议操作 |
|---------|---------|-----------|---------|
| < 100 | < 500ms | 极佳 | 无限制 |
| 100-500 | 500ms-1s | 良好 | 建议关闭"显示全部标签" |
| 500-1000 | 1-2s | 中等 | 使用搜索过滤 + 关闭标签 |
| > 1000 | 2-5s | 较慢 | 强烈建议过滤 + 分批查看 |

**优化建议**：
- 大数据集时优先使用搜索和状态过滤
- 固定关键节点后再拖拽其他节点
- 导出前先调整好视图再截图
